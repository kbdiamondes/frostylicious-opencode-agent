- Optimizing landing pages for higher conversion rates

## Steps

### Step 1: PBCH Brand Campaign CPA Reduction

**Current:** ~$83 CPL → **Target:** < $50 CPL

#### 1.1 Audit Current Campaign
1. Pull last 30 days data: Google Ads → Campaigns → PBCH Brand
2. Check:
   - Search terms report (what keywords trigger ads)
   - Quality Score (landing page experience, ad relevance, expected CTR)
   - Ad copy performance (CTR, conversion rate)
   - Landing page conversion rate

#### 1.2 Add Negative Keywords
1. Go to Keywords → Search Terms
2. Identify irrelevant searches:
   - DIY, cheap, free, jobs, salary, training
   - Competitor names (if not targeting)
   - Locations outside service area
3. Add as negative keywords (phrase match)

#### 1.3 Improve Ad Copy
1. Create 3 new RSA variations:
   - **Variation 1:** Benefit-focused ("Hassle-Free Event Setup in Perth")
   - **Variation 2:** Social proof ("Trusted by 100+ WA Schools")
   - **Variation 3:** Urgency ("Book Now for School Holidays")
2. Pin best-performing headlines to positions 1-2
3. Include keyword in at least 2 headlines

#### 1.4 Optimize Landing Page
1. Check page speed (target < 3 seconds)
2. Ensure form is above the fold
3. Add social proof (testimonials, school logos)
4. Clear CTA ("Get a Free Quote")
5. Mobile-responsive check

#### 1.5 Adjust Bidding
1. Switch to Target CPA bidding (set target at $50)
2. Or use Maximize Conversions with manual CPC ceiling
3. Start with 20% budget increase on winners

### Step 2: Scale Top Performers

**Dunk Tanks ($38.97 CPL) and Laser Tag ($44.49 CPL)**

1. Increase budget by 20-30%:
   - Dunk Tanks: $20/day → $25-26/day
   - Laser Tag: $18/day → $22-24/day
2. Monitor for 7 days
3. If CPA stays < $50, increase another 20%
4. If CPA rises > $50, pause increase and optimize

### Step 3: Test New RSA Variations

For each campaign, create 2-3 new RSAs:

**Headline Formula:**
- H1: Keyword-focused ("Dunk Tank Hire Perth")
- H2: Benefit-focused ("Fun for All Ages")
- H3: CTA ("Get a Free Quote Today")

**Description Formula:**
- D1: Specific activities + location
- D2: Trust + logistics (we handle setup)
- D3: CTA + urgency

**Examples:**

```
Headlines:
1. Dunk Tank Hire Perth (22)
2. School Event Activities WA (27)
3. Get a Free Quote Today (22)
4. Fun, Safe, Professional (23)
5. We Handle Setup & Pack Down (27)

Descriptions:
1. Dunk tanks, laser tag, foam machines. Perth's #1 school event supplier. (68)
2. We deliver, set up, and pack down. You enjoy the day. Get a free quote. (72)
3. Trusted by 100+ WA schools. Safe, fun, professional. Book now. (63)
```

### Step 4: Landing Page CRO

**For School LP:**
1. Add above-the-fold CTA ("Get a Free Quote")
2. Show 3-5 activity photos (dunk tank, laser tag, silent disco)
3. Add testimonials from WA schools
4. Simplify form (name, email, phone, event date, school name)
5. Add trust badges (insured, Working with Children Check)

**For Sports LP:**
1. Emphasize action photos (kids participating)
2. Add "Book Now" button on mobile
3. Show pricing transparency (from $X per student)
4. Add FAQ section (ages, safety, logistics)

### Step 5: Monitor and Iterate

**Daily (first 2 weeks):**
- Check CPA by campaign
- Pause any campaign with CPL > $100 for 3+ days
- Scale any campaign with CPL < $40

**Weekly:**
- Pull search terms report → add negatives
- Review ad copy CTR → pause low performers
- Check landing page conversion rate

**Bi-weekly:**
- Create new RSA variations (2-3 per campaign)
- Test new audience segments if available
- Compile performance report
